rege

Um orquestrador de IAs no terminal. Um modelo mestre recebe a tarefa, decide se ela é fácil ou difícil e manda outras IAs de linha de comando — Claude Code, Codex, Gemini — trabalharem em paralelo, cada uma isolada no seu próprio git worktree dentro do tmux.

Depois ele revisa o que cada uma fez, junta o melhor, roda os testes e abre um pull request. Merge, nunca: quem aprova é gente.

  • Tarefa fácil: divide em partes, cada worker pega uma.
  • Tarefa difícil: vários fazem a mesma coisa e o mestre julga.
  • Começou em Ruby e virou Rust. Código aberto, licença MIT.
